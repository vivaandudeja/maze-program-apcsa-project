Install & Run

Pick whichever method fits your style.

Installer (recommended)

  1. Click Download for Windows above
  2. Run MazeProgram-1.0.0.exe
  3. Walk through the Setup wizard
  4. Launch from the Start menu — done

Portable ZIP

  1. Download Portable ZIP above
  2. Right-click the .zip → Extract All
  3. Open the extracted folder
  4. Double-click MazeProgram.exe
Heads up: Windows may show “Windows protected your PC” on first launch. This appears for any unsigned executable. Click More info → Run anyway to continue.

About

Built as an AP Computer Science A final project.

What's under the hood

  • Written in Java (4 classes, ~350 LOC)
  • Maze generation: recursive backtracking (DFS)
  • Maze solving: depth-first search with path marking
  • Image rendering: java.awt.image.BufferedImage
  • Native file dialogs: java.awt.FileDialog

What's bundled

  • Native Windows launcher (jpackage)
  • Slim custom JRE (jlink) — no Java install required
  • 5 modules from JDK 25: java.base, java.desktop, and dependencies
  • Installer built with WiX Toolset
